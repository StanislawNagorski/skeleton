## Architecture

### Clean Architecture Layers
Summarize the 3-layer pattern: data (sources, models, repositories), domain (services, entities), presentation (pages, cubits, widgets). Each feature lives under `lib/features/<feature>/` with these three subdirectories. Core shared code lives under `lib/core/`.

### State Management
flutter_bloc 9 with Cubit<State>. State is immutable with factory .initial() and copyWith. Status surfaces via enum (loading, success, error, empty).

### Error Handling (sealed Result<T> / AppFailure)
Dart 3 sealed Result<T> replaces dartz Either. Repositories return Result<T>, cubits consume via exhaustive switch. AppFailure sealed hierarchy with named constructors. No fold() — pattern matching only.

### Routing (auto_route 11)
RootStackRouter with guards property. OnboardingGuard (global, runs first) + AuthGuard (per-route on LoginRoute only). reevaluateListenable via Listenable.merge combining auth stream + onboarding notifier.

### Dependency Injection (get_it + injectable)
@Injectable(as: AbstractType) pattern. DI environment switching: 'prod' registers FirebaseAuthService, 'dev' registers FakeAuthService. configureDependenciesApp(environment: env) called after startup determines Firebase availability.

### AuthService Contract
