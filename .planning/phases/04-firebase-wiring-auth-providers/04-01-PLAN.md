**1. Create `lib/firebase_options.dart`** — a stub file that allows compilation on fresh clones without `flutterfire configure`. This file gets OVERWRITTEN by `flutterfire configure` when the developer sets up Firebase. Content:

```dart
// ignore_for_file: type=lint
// GENERATED BY FlutterFire CLI — overwritten by `flutterfire configure`.
// This stub allows `flutter run` without Firebase configured.
// Run `flutterfire configure` to replace this file with real options.

import 'package:firebase_core/firebase_core.dart' show FirebaseOptions;

/// Stub [DefaultFirebaseOptions] for fresh-clone compatibility.
///
/// `StartUpService` catches the [UnsupportedError] thrown here and
/// falls back to the `'dev'` DI environment (which registers
/// [FakeAuthService] instead of [FirebaseAuthService]).
class DefaultFirebaseOptions {
  static FirebaseOptions get currentPlatform => throw UnsupportedError(
        'No Firebase configuration found. '
        'Run `flutterfire configure` to generate firebase_options.dart.',
      );
}
```

**2. Update `lib/core/injectable/injection.dart`** — add the `environment` named parameter to `configureDependenciesApp` and forward it to `$initGetIt`. The generated `$initGetIt` already accepts `String? environment` (confirmed in injection.config.dart). Change:

```dart
Future<void> configureDependenciesApp() async => $initGetIt(getIt);
```

To:

```dart
Future<void> configureDependenciesApp({String environment = 'dev'}) async =>
```

Keep all existing imports and annotations unchanged.

To:

```dart
@LazySingleton(as: AuthService, env: [Environment.dev])
```

Add `import 'package:injectable/injectable.dart';` if not already present (it is already imported — `injectable` is used for `@LazySingleton`). The `Environment` class is from `package:injectable/injectable.dart`.
