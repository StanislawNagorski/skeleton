Per D-12 / TOOL-07:

Create `test/tool/bootstrap_test.dart` -- an end-to-end test that:

1. **Setup** -- Copies the project root to `Directory.systemTemp.createTempSync('bootstrap_test_')`. Use `dart:io` to recursively copy files. IMPORTANT: Skip the following directories during copy to keep it fast and avoid issues:
   - `.dart_tool/`
   - `.fvm/`
   - `build/`
   - `.git/`
   - `linux/`, `macos/`, `windows/` (not relevant)

2. **Execute** -- Runs `dart run tool/bootstrap.dart --name TestApp --bundle com.test.myapp` in the temp directory using `Process.run('dart', ['run', 'tool/bootstrap.dart', '--name', 'TestApp', '--bundle', 'com.test.myapp'], workingDirectory: tempDir.path)`. Asserts exit code 0. Asserts stdout contains "Bootstrap complete!" (the post-run checklist header).

3. **Verify rename targets** -- After the script runs, read key files and assert:
   - `pubspec.yaml` contains `name: test_app` (snake_case of TestApp)
   - `pubspec.yaml` does NOT contain `name: skeleton`
   - `android/app/build.gradle.kts` contains `namespace = "com.test.myapp"`
   - `android/app/build.gradle.kts` does NOT contain `com.example.skeleton`
   - `ios/Runner.xcodeproj/project.pbxproj` contains `com.test.myapp`
   - `ios/Runner.xcodeproj/project.pbxproj` does NOT contain `com.example.skeleton`
   - `ios/Runner/Info.plist` contains `<string>TestApp</string>` (display name)
   - `README.md` starts with `# TestApp`
   - `lib/core/database/app_database.dart` contains `'test_app_db'`
   - `android/app/src/main/kotlin/com/test/myapp/MainActivity.kt` exists
   - `android/app/src/main/kotlin/com/example/skeleton/` does NOT exist
   - No `.dart` file under `lib/` contains `package:skeleton/` (spot check 3-5 files: `lib/main.dart`, `lib/app.dart`, `lib/startup_service.dart`)

4. **Verify analyze** -- Run `dart analyze lib/` in the temp directory (NOT full `flutter analyze` which requires SDK setup). Asserts exit code 0 (no broken imports). Use a generous timeout of 120 seconds.

5. **Verify input validation** -- Test that invalid inputs are rejected:
   - Run with `--name "" --bundle com.test.app` -- assert exit code 1
   - Run with `--name My/App --bundle com.test.app` -- assert exit code 1
   - Run with `--name MyApp --bundle invalid` -- assert exit code 1
   - Run with no args -- assert exit code 1

6. **Teardown** -- Delete the temp directory in `tearDown`.

**Test structure:**
- Use `@Timeout(Duration(minutes: 3))` annotation on the test file (file copy + dart analyze can be slow).
- Group: `'Bootstrap script E2E'`
- `setUpAll`: copy project to temp dir
- `tearDownAll`: delete temp dir
- Individual `test()` calls for: successful rename, file verification, analyze pass, input validation

**Important:** This is a `dart:test` test (not `flutter_test`) since it only does file I/O and process spawning. Import `package:test/test.dart`. However, since the project uses `flutter_test` (which re-exports `test`), import `package:flutter_test/flutter_test.dart` for consistency.

**Helper function:**
- `Future<void> _copyDirectory(Directory source, Directory destination)` -- recursively copies, skipping the excluded directories listed above.
