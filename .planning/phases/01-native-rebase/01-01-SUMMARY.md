## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Flutter 3.41.5 ships Dart 3.11.3 (not 3.9 as estimated)**
- **Found during:** Task 1
- **Issue:** The plan estimated Dart 3.9.0 based on research. Actual SDK is 3.11.3.
- **Fix:** Kept `sdk: ^3.9.0` floor constraint as planned -- it is forward-compatible with 3.11.3.
- **Impact:** None -- constraint works correctly as a minimum version.

**2. [Rule 3 - Blocking] Gradle build scripts now use Kotlin DSL (.kts)**
- **Found during:** Task 2
- **Issue:** Flutter 3.41.5's `flutter create` generates `settings.gradle.kts`, `build.gradle.kts`, and `app/build.gradle.kts` instead of Groovy `.gradle` files.
- **Fix:** Accepted fresh template output as authoritative (per plan instruction: "accept the fresh template output as authoritative").
- **Files affected:** android/settings.gradle.kts, android/build.gradle.kts, android/app/build.gradle.kts

**3. [Rule 3 - Blocking] No Podfile in fresh Flutter 3.41.5 scaffold (SPM default)**
- **Found during:** Task 2
- **Issue:** Flutter 3.41.5 defaults to Swift Package Manager -- no Podfile generated by `flutter create`.
- **Fix:** `flutter pub get` auto-generated a Podfile because project plugins (Firebase, ObjectBox) still require CocoaPods. Set platform floor to 15.0 in the auto-generated Podfile.
- **Files affected:** ios/Podfile, ios/Podfile.lock

**4. [Rule 3 - Blocking] `intl` constraint incompatible with Flutter 3.41.5**
- **Found during:** Task 3
- **Issue:** `intl: ^0.19.0` conflicts with `flutter_localizations` SDK-pinned `intl 0.20.2`.
- **Fix:** Updated constraint to `intl: ^0.20.2`.
- **Files modified:** pubspec.yaml

**5. [Rule 3 - Blocking] L10n synthetic package no longer generated**
- **Found during:** Task 3
- **Issue:** Flutter 3.41.5 generates l10n files in-place (`lib/core/localization/`) instead of the `flutter_gen/gen_l10n/` synthetic package. `flutter analyze` showed 6 errors from broken imports.
- **Fix:** Updated imports in `lib/app.dart` and `lib/core/extensions/context_extension.dart` from `package:flutter_gen/gen_l10n/app_localizations.dart` to `package:skeleton/core/localization/app_localizations.dart`.
- **Files modified:** lib/app.dart, lib/core/extensions/context_extension.dart
- **Note:** These are `lib/` source changes. The plan said "preserve lib/ verbatim" but these imports were broken by the SDK upgrade and are a direct consequence of the rebase.

**6. [Rule 3 - Blocking] iOS Flutter.xcframework not precached**
- **Found during:** Task 3
- **Issue:** `pod install` failed because `Flutter.xcframework` was not yet downloaded for iOS.
- **Fix:** Ran `fvm flutter precache --ios` before retrying `pod install`.
- **Impact:** None -- one-time cache population.

### Notable Template Changes (Accepted as-is)

- **Java target 17:** Fresh template uses `JavaVersion.VERSION_17` (was 1.8). Correct for modern Android development.
- **SceneDelegate pattern:** iOS now uses SceneDelegate.swift (new in 3.41.5 template). UIKit lifecycle modernization.
- **CADisableMinimumFrameDurationOnPhone:** Present in fresh template by default (was previously a custom addition).
- **No MinimumOSVersion in AppFrameworkInfo.plist:** 3.41.5 removed this key. iOS floor is set via IPHONEOS_DEPLOYMENT_TARGET in project.pbxproj (15.0).
- **Gradle JVM args:** Fresh template uses `-Xmx8G -XX:MaxMetaspaceSize=4G -XX:ReservedCodeCacheSize=512m` (more generous than the old 4G/2G).

## Decisions Made

1. **Kotlin DSL accepted:** Flutter 3.41.5 generates .kts Gradle files. All downstream plans referencing `build.gradle` or `settings.gradle` must use the `.kts` variants.
2. **Dart SDK constraint:** Using `^3.9.0` floor with actual SDK 3.11.3. Provides forward compatibility.
3. **CocoaPods retained:** Despite Flutter 3.41.5 defaulting to SPM, CocoaPods is still needed for Firebase and ObjectBox plugins. Podfile is auto-generated by `flutter pub get`.
4. **L10n in-place generation:** Generated l10n files are now committed to `lib/core/localization/` instead of being synthetic. Imports updated accordingly.
5. **intl constraint bumped:** `^0.19.0` to `^0.20.2` to match SDK-pinned version. This is technically a dependency change (plan said "touch only environment block") but is required for `flutter pub get` to succeed.
