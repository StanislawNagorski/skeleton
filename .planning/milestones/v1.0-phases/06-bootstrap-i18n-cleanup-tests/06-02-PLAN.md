Per D-01, D-02, D-03, D-04, D-05:

Create `tool/bootstrap.dart` -- a pure Dart CLI script using only `dart:io` (per D-03). No external package dependencies.

**Argument parsing:**
- Parse `--name <AppName>` and `--bundle <com.foo.app>` from command-line args.
- Use simple manual parsing: iterate args looking for `--name` and `--bundle` flags, take the next arg as the value.
- If either is missing, print usage and exit with code 1.

**Input validation (per D-04):**
- `--name`: Must be non-empty, contain only alphanumeric characters (no spaces, slashes, dots, or shell metacharacters). Regex: `^[a-zA-Z][a-zA-Z0-9]*$`. Print descriptive error and exit 1 if invalid.
- `--bundle`: Must be valid reverse-domain format with at least 3 segments. Regex: `^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*){2,}$`. Print descriptive error and exit 1 if invalid.

**Derived values:**
- `dartPackage` = convert `--name` to snake_case (e.g., `MyApp` -> `my_app`, `TodoList` -> `todo_list`). Use a helper that inserts `_` before uppercase letters and lowercases everything.
- `displayName` = `--name` as-is (preserves casing for UI display)
- `bundleId` = `--bundle` as-is
- `bundlePath` = `--bundle` with dots replaced by `/` (for Android Kotlin directory structure)

**Rename operations (execute in this order):**

1. **Dart package imports** -- Recursively find all `.dart` files under `lib/` (including generated files like `injection.config.dart`, `router.gr.dart`, `app_database.g.dart`, localization files). Replace `package:skeleton/` with `package:$dartPackage/` in each file.

2. **Android build.gradle.kts** -- In `android/app/build.gradle.kts`, replace `namespace = "com.example.skeleton"` with `namespace = "$bundleId"` and `applicationId = "com.example.skeleton"` with `applicationId = "$bundleId"`.

3. **Android AndroidManifest.xml** -- In `android/app/src/main/AndroidManifest.xml`, replace `android:label="skeleton"` with `android:label="$displayName"`.

4. **Android Kotlin directory** --
   a. Read `android/app/src/main/kotlin/com/example/skeleton/MainActivity.kt`
   b. Replace `package com.example.skeleton` with `package $bundleId`
   c. Create new directory at `android/app/src/main/kotlin/$bundlePath/`
   d. Write the updated `MainActivity.kt` to the new directory
   e. Delete the old file and recursively delete empty parent directories back to `kotlin/`

5. **iOS project.pbxproj** -- In `ios/Runner.xcodeproj/project.pbxproj`, replace ALL occurrences of `com.example.skeleton` with `$bundleId` (there are 6: 3 for Runner, 3 for RunnerTests).

6. **iOS Info.plist** -- In `ios/Runner/Info.plist`, replace `<string>Skeleton</string>` (CFBundleDisplayName value) with `<string>$displayName</string>`, and the `<string>skeleton</string>` (CFBundleName value) with `<string>$dartPackage</string>`.

7. **pubspec.yaml** -- Replace `name: skeleton` with `name: $dartPackage`. Replace the description line: find the line starting with `description:` and replace its content with `description: "$displayName Flutter application."`.

8. **README.md** -- Replace the first line `# Skeleton - Flutter App Template` with `# $displayName`.

9. **Drift database name** -- In `lib/core/database/app_database.dart`, replace `'skeleton_db'` with `'${dartPackage}_db'`.

**Progress output:**
- Print each step as it executes: `[1/9] Renaming Dart package imports...`, `[2/9] Updating Android build.gradle.kts...`, etc.
- Print total files modified count at the end.

**Post-run checklist (per D-05 / TOOL-02):**
After all renames complete, print to stdout:

```
Bootstrap complete! $displayName ($bundleId) is ready.

Next steps:
  1. Run: fvm flutter pub get
  2. Run: dart run build_runner build --delete-conflicting-outputs
  3. Create a Firebase project at https://console.firebase.google.com
  4. Register Android app with package name: $bundleId
  5. Register iOS app with bundle ID: $bundleId
  6. Download google-services.json -> android/app/
  7. Download GoogleService-Info.plist -> ios/Runner/
  8. Run: flutterfire configure --project=<your-firebase-project-id>
  9. Register SHA-1 fingerprints:
     - Debug:   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android
     - Release: keytool -list -v -keystore <your-release-keystore> -alias <your-alias>
  10. Apple Sign-in: Enable "Sign in with Apple" capability in Xcode
  11. Apple Sign-in: Configure Services ID at https://developer.apple.com
  12. Run: fvm flutter run
```

**Error handling:**
- If any file read/write fails, print the error and exit with code 2.
- Wrap the main execution in a try/catch that prints a clear error message.

- `String _parseArg(List<String> args, String flag)` -- extracts arg value after flag
- `void _validateName(String name)` -- validates and exits on failure
- `void _validateBundle(String bundle)` -- validates and exits on failure
- `void _replaceInFile(String path, String from, String to)` -- reads file, replaces all occurrences, writes back
- `void _replaceInDartFiles(String directory, String from, String to)` -- recursively processes .dart files
- `void _moveKotlinDir(String oldBundle, String newBundle)` -- handles Android Kotlin dir restructure
