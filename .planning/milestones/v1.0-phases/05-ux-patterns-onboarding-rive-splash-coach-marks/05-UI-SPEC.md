# Phase 5 — UI Design Contract

> Visual and interaction contract for the onboarding flow, coach mark overlays, and RIVE demo page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Flutter Material 3 (`ColorScheme.fromSeed`) |
| Preset | not applicable |
| Component library | Material 3 widgets (existing `AppThemes.light`) |
| Icon library | `cupertino_icons` (already in pubspec) + Material Icons |

## Spacing Scale

Declared values (must be multiples of 4). Extends existing `AppDimensions` tokens:

| Token | Value | Constant | Usage in this phase |
|-------|-------|----------|---------------------|
| xs | 4px | `AppDimensions.spacingSmall` | Dot indicator gaps, icon-to-text inline spacing |
| sm | 8px | `AppDimensions.spacingBase` | Coach mark tooltip internal padding |
| md | 16px | `AppDimensions.spacingMedium` | Onboarding slide content padding, button spacing |
| lg | 24px | `AppDimensions.spacingLarge` | Section gaps between title/subtitle/image on slides |
| xl | 32px | `AppDimensions.spacingExtraLarge` | Top/bottom safe-area padding on onboarding pages |
| 2xl | 48px | *New:* `AppDimensions.spacingXXL` | Vertical gap above onboarding illustration |
| 3xl | 64px | *New:* `AppDimensions.spacingXXXL` | Bottom padding below "Get Started" CTA |

Exceptions:
- Coach mark spotlight padding: 12px (uses `AppDimensions.radiusMedium` repurposed as overlay padding around target)
- Dot indicator dot size: 8px active, 8px inactive (circle diameter, not spacing)

## Typography

Uses Material 3 `TextTheme` from `ColorScheme.fromSeed(seedColor: AppColors.primary)`. Phase 5 screens use these specific roles:

| Role | TextTheme Style | Approx Size | Weight | Line Height |
|------|----------------|-------------|--------|-------------|
| Slide title | `headlineMedium` | 28px | w400 (regular) | 1.2 |
| Slide subtitle | `bodyLarge` | 16px | w400 (regular) | 1.5 |
| Button label | `labelLarge` | 14px | w500 (medium) | 1.2 |
| Coach mark title | `titleMedium` | 16px | w500 (medium) | 1.2 |
| Coach mark body | `bodyMedium` | 14px | w400 (regular) | 1.5 |
| RIVE demo heading | `headlineSmall` | 24px | w400 (regular) | 1.2 |
| RIVE demo body | `bodyMedium` | 14px | w400 (regular) | 1.5 |

Weights used: w400 (regular) + w500 (medium). No bold/semibold in this phase.

Source: Material 3 default `TextTheme` from seed color. No custom font registration needed.

## Color

Uses `ColorScheme.fromSeed(seedColor: Color(0xFF3643BA))` which generates a full Material 3 palette.

| Role | ColorScheme Property | Usage in this phase |
|------|---------------------|---------------------|
| Dominant (60%) | `colorScheme.surface` | Onboarding page background, RIVE demo background |
| Secondary (30%) | `colorScheme.surfaceContainerHighest` | Coach mark tooltip background, onboarding dot inactive color |
| Accent (10%) | `colorScheme.primary` | "Get Started" / "Next" button fill, active dot indicator, coach mark spotlight ring, RIVE demo toggle switch active state |
| On-accent text | `colorScheme.onPrimary` | Button label text on accent-colored buttons |
| Muted text | `colorScheme.onSurfaceVariant` | "Skip" button text, slide subtitle text |
| Coach mark overlay | `Colors.black.withOpacity(0.7)` | Semi-transparent backdrop behind spotlight |

Accent reserved for:
- "Get Started" filled button on last onboarding slide
- "Next" filled button on onboarding slides 1-2
- Active dot in page indicator
- Coach mark spotlight ring (thin border around highlighted target)
- RIVE demo state-machine toggle active state

Destructive: not used in this phase (no destructive actions).

## Interaction Contracts

### Onboarding

| Interaction | Behavior |
|-------------|----------|
| Swipe left/right | Advances/retreats slides. Dot indicator updates. Button label updates on last slide. |
| Tap "Next" | Animates to next slide (`PageController.nextPage`, 300ms, `Curves.easeInOut`) |
| Tap "Get Started" | Persists `hasSeenOnboarding=true` via `PreferencesService.setBool()`, navigates to `HomeRoute` |
| Tap "Skip" | Same as "Get Started" -- persists flag, navigates to Home immediately |
| Back gesture (Android) | No-op on first slide. On slides 2-3, goes to previous slide (not exit onboarding) |

### Coach Marks

| Interaction | Behavior |
|-------------|----------|
| Tour start | Automatic on first visit to counter page. `addPostFrameCallback` ensures targets are laid out. |
| Tap outside spotlight | Advances to next target. On last target, closes overlay. |
| Tour completion | Persists `tour_home_seen=true` via `PreferencesService`. Tour never auto-shows again. |
| Target 1 | Counter display value -- tooltip: "This is your counter" / "Tap the button below to increment it" |
| Target 2 | FAB -- tooltip: "Increment" / "Tap this button to increase the counter" |

### RIVE Demo

| Interaction | Behavior |
|-------------|----------|
| Toggle switch | Sends boolean input to RIVE state machine. Animation state changes accordingly. |
| Back navigation | Returns to Home. RIVE controller disposed in `StatefulWidget.dispose()`. |

## Accessibility

| Concern | Spec |
|---------|------|
| Minimum touch target | 48x48px for all interactive elements (Material default) |
| Onboarding dot indicator | Decorative only -- swipe and buttons provide navigation. No `Semantics` label on individual dots. |
| Skip button | `Semantics(label: 'Skip onboarding')` |
| Coach mark overlay | `Semantics(liveRegion: true)` on tooltip text so screen readers announce coach mark content |
| RIVE animation | `Semantics(label: 'Animated demo')` -- animations are decorative, state toggle has its own label |
| Color contrast | All text meets WCAG 2.1 AA (4.5:1 body, 3:1 large text) -- enforced by Material 3 `ColorScheme.fromSeed` |
